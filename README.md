# BurnCare AI – AI-Based Web Application

**Description:**  
A web application that predicts patient mortality risk trends based on vital-sign data using AI.

**Technologies:** TypeScript, FastAPI, Python (AI Model), HTML/CSS

**Features:**  
- Input patient vitals and generate mortality risk predictions  
- Interactive frontend for data input and visualization  
- AI model integration for real-time risk analysis

**My Contributions:**  
- Developed full-stack architecture (frontend + backend)  
- Integrated AI model with FastAPI backend  
- Designed and connected frontend interface

**How to Run:**  
1. Clone the repository: `git clone https://github.com/yourusername/burncare-ai.git`  
2. Install backend dependencies: `pip install -r requirements.txt`  
3. Run FastAPI server: `uvicorn main:app --reload`  
4. Open frontend in browser
